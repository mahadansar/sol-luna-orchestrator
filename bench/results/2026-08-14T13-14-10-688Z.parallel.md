## Measurement notes

- Wall-clock is measured by the harness around the whole supervisor turn, so it includes delegation and integration overhead.
- Supervisor tokens come from the Codex SDK's `turn.completed` event. Worker tokens come from the orchestrator's own delegation telemetry.
- For batch (`delegate_tasks`) runs only worker OUTPUT tokens are recorded, so the input-token column understates the orchestrated arms. It is reported as measured rather than estimated.
- Pass/fail is decided by the harness after the agent stops: task checks must exit 0 and files marked immutable must be byte-identical. The agent never grades itself.
- **Cost in currency is not measurable here.** The API exposes token counts, not prices, and the arms use different models at different efforts.
- Sample sizes are small. Treat these as directional, not statistically significant.
