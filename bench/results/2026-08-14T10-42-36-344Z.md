## What these numbers do and do not show

- Wall-clock and token counts are measured directly: supervisor usage from the Codex SDK's `turn.completed` event, worker usage from the orchestrator's own delegation records.
- Pass/fail is decided by this harness after the agent stops, by running the task's checks and hashing files that were supposed to stay untouched. The agent never grades itself.
- **Cost in currency is not measurable from this integration.** The API exposes token counts, not prices, and this project has no reliable pricing data for these models. Token counts are reported instead.
- Cached input tokens are reported by the API but their billing treatment is not, so input tokens are not aggregated into a single cost-like figure.
- The sample is small. Treat single-digit repetition counts as directional, not statistically significant.
